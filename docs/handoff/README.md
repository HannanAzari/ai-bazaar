# Nestudio — CTO Handoff Package

> The permanent onboarding package. A brand-new session (AI or human) should become productive in ~10 minutes from these files alone, with **no prior chat history required**.

## Reading order

```
1. 01_READ_FIRST          ← the only thing you must read first (~10 min)
        ↓
2. 02_PROJECT_STATE       ← where implementation actually is
        ↓
3. 03_DESIGN_CONSTITUTION ← the permanent design system (philosophy → grammar → sound)
        ↓
4. 04_TECHNICAL_ARCHITECTURE ← the target architecture (UOS) + current codebase
        ↓
5. 06_NEXT_SPRINT         ← start working here
```

Then reference as needed: **05_ROADMAP** · **07_DECISIONS** · **08_GLOSSARY** · **09_REPOSITORY_STRUCTURE** · **10_FUTURE_RULES**.

## What each file is

| File | Purpose | Cadence |
|---|---|---|
| `01_READ_FIRST` | What/why/different, phase, priorities, what's frozen, what's postponed | Rarely changes |
| `02_PROJECT_STATE` | Completed / in-progress / blocked / risks / debt | **Every sprint** |
| `03_DESIGN_CONSTITUTION` | Consolidated philosophy + alphabet + grammar + interaction/sound/business/memory | Permanent |
| `04_TECHNICAL_ARCHITECTURE` | UOS + room/object/surface/animation/sound systems + current code | On architecture change |
| `05_ROADMAP` | Phases 0–7 with goals, exits, metrics | On milestone change |
| `06_NEXT_SPRINT` | The active working doc | **Every sprint** |
| `07_DECISIONS` | Append-only decision log | On every major decision |
| `08_GLOSSARY` | Every term defined once | On new term |
| `09_REPOSITORY_STRUCTURE` | Where docs live | Rarely |
| `10_FUTURE_RULES` | The non-negotiable working rules | Rarely |
