# M19.1 — Arrival Magic & Atmosphere (branch `m12-nest-platform`)

> **Preview only.** Shipped on `m12-nest-platform`. **No merge to `main`, no production deploy.**
> Not a feature sprint — a *feeling* sprint. The M19 `Village → House → Nest` gained a **time of
> day**, **weather**, **house life**, a **cinematic camera**, and a **round-trip door**, so opening a
> Nest feels like *arriving at someone's place*. No auth / marketplace / AI / multiplayer /
> migrations. Canonical record; see [changelog.md](changelog.md) and ADR-040.

## Success metric

> "Does opening a Nest feel magical?" — a sky that changes through the day, houses that breathe, a
> camera that moves with intent, and a door you cross both ways.

## Phase 0 — the arrival flow before M19.1

- **Journey:** `/village` → tap house → **instant** overlay → **instant** door → jump into the Nest,
  under a village that looks identical every visit.
- **Pain points:** the tap→overlay is a *cut* (no camera); the village has no time/weather so no
  emotional pull; the house front lacks avatar/stats/presence depth; leaving a Nest is an abrupt jump.
- **Opportunities:** time of day (biggest lift, cheap), a cinematic zoom, house life, weather, richer
  arrival, a door round trip, and an audio seam — all achievable with pure CSS + deterministic data.

## Architecture

Everything is **pure, deterministic, and dependency-free** (no motion library, no audio files, no
APIs, no storage, no `Math.random`/`Date.now` in render) so it stays hydration-safe + testable and
can't drift the data model.

```
lib/nest-atmosphere.ts   time of day (timeOfDay + SKY_THEMES) · deterministic weather
                         (weatherForDay / weatherFromSeed + WEATHER_THEMES)
lib/nest-ambience.ts     audio ARCHITECTURE only — AMBIENCE_SCENES + ambienceForScene,
                         behind ENABLE_NEST_AUDIO (default OFF). No files, nothing plays.
lib/nest-house.ts        houseFeatures(seed) → roof · window · door · garden · mailbox;
                         House gains nestCount
        │
        ▼
components/nest/village/
  use-atmosphere.ts      shared hook — computes time+weather AFTER mount (SSR default
                         afternoon/clear → no hydration mismatch), then settles
  scene-backdrop.tsx     sky/sun/moon/stars/clouds/hills + rain/snow particles + birds
  house-exterior.tsx     features + night glow + swaying tree + smoke + lit windows
  village-scene.tsx      CINEMATIC CAMERA — tapping zooms the board toward the house
                         (transform + blur) while the neighborhood softens
  house-front.tsx        arrival polish — avatar · bio · followers · nests · online ·
                         time·weather chip · Enter (camera-forward door)
  enter-transition.tsx   DoorTransition mode "enter" (open + flood + push forward) /
                         "exit" (door closes back) — the round trip
app/globals.css          nest-twinkle/birds/flap/rain/snow/sway/cam-forward/door-close
```

## What shipped (by phase)

- **1 · Cinematic camera** — tap a house → the board zooms toward it (CSS `transform: scale` at the
  house's origin + blur/dim) while the neighborhood softens, then the arrival panel rises. Reduced-
  motion skips the delay.
- **2 · House life** — chimney smoke (when home), softly breathing lit windows, a swaying tree,
  drifting clouds, an occasional bird (skipped at night / in rain). Nintendo-level restraint.
- **3 · Time of day** — Morning / Afternoon / Evening / Night from the visitor's clock: the sky,
  sun/moon + stars, light wash, hills, and **window glow** all change; night lights every window.
- **4 · Weather** — a deterministic **daily rotation** (one sky for the whole village): sunny /
  cloudy / rain / snow, with subtle CSS particles + an overcast wash.
- **5 · Arrival polish** — creator avatar · bio · **now-showing Nest** · **followers** · **nests** ·
  online indicator · a live **time · weather** chip · Enter. Airbnb arrival + Animal Crossing house.
- **6 · Door round trip** — **Enter** opens the door, floods warm light, and **pushes the camera
  forward** before the Nest loads.
- **7 · Ambient audio architecture** — a scene registry + deterministic resolver behind
  **`ENABLE_NEST_AUDIO`** (default OFF). **No files, nothing plays** — the seam only, for a later
  sprint (village / rain / birds / fireplace / coffee-shop / waves / wind / crickets).
- **8 · House identity expansion** — seed-derived **roof shape · window shape · door type · garden
  decoration · mailbox**; still deterministic, still no editor.
- **9 · Return journey** — the Nest page gains an **Exit** that **closes the door** and returns you
  to the house / village (history-aware) — not an abrupt jump.
- **10 · Mobile** — verified on 375×812 (below).
- **11 · Gates** — `typecheck · lint · test (402) · build` all green (Node 20).

## Verification (browser, mobile 375×812)

- **Village** renders under a live **Afternoon · Rain** sky (rain particles, overcast wash, cooler
  light) with clearly varied house features (arch/round/square doors + windows, mailboxes, flower/
  bush/lantern gardens).
- **Cinematic arrival:** tapping *Creator Loft* softens the neighborhood and opens the arrival panel
  (weather chip · presence · detailed house · door plate · now-showing · prev/next · Enter · time
  note).
- **Enter → door + camera-forward → composed Nest.**
- **Exit → door closes → back to the Village** (full round trip).
- **Night:** forcing the clock to 21:00 turns the village to **Night** — deep blue sky, a moon, every
  window glowing, lit garden lanterns — a dramatic mood shift from the same houses by day.
- **No console errors** on any surface.

## Performance notes

- **CSS-transform only** for the camera (scale/opacity/blur transitions) and all ambient motion
  (`translate`/`opacity`/`scale` keyframes) — GPU-friendly, no layout thrash, no JS animation loop.
- **Particle budgets are small** and deterministic: ≤34 rain / ≤26 snow / ≤26 stars, positioned from
  an index hash (no `Math.random`), so no runtime cost beyond compositing.
- **No new runtime dependency** (no framer-motion) — bundle unchanged beyond the small libs; `/village`
  is ~7 kB.
- **Reduced motion** zeroes animation durations globally and the Enter/Exit + camera skip their delays.

## Known limitations

- **Time of day is the visitor's local clock** (not the creator's / a server time), and **weather is
  cosmetic** (a deterministic daily rotation, not real conditions).
- **Ambient audio is architecture only** — the flag is OFF and no sound files ship; a later sprint
  adds a gesture-gated player + loops.
- **The cinematic zoom is a CSS transform** toward the house's board position (not a true scene-graph
  camera); it reads as a push-in but doesn't re-center perfectly when the board is scrolled.
- Stats on the arrival panel are shown for **real creators** only (generated neighbors / curated
  show-homes have no follower/nest data).

## Future recommendations

- **Ship the audio** behind the existing seam: a gesture-gated loop player + a mute control + the
  loops; `ambienceForScene` already picks the right bed from weather/time/persona.
- **Creator-controlled atmosphere** — let a creator pin a mood (e.g. always-dusk, always-rain) for
  their house, and/or use the creator's timezone.
- **A true camera** — a parallax, scroll-aware push-in (foreground/mid/background layers) and a
  walking avatar between houses for the full `world → zoom → village → house` descent.
- **Seasonal + event skies** — deterministic seasonal palettes and special-day atmospheres.

## Do not accidentally change

- **Compute time/weather AFTER mount** (`use-atmosphere.ts`) with a stable SSR default — computing at
  render time reintroduces a hydration mismatch.
- **Unsigned shifts in `houseFeatures`** (`>>>`) — a signed `>>` on a seed ≥ 2³¹ yields a negative
  modulo → an undefined feature.
- **Deterministic particles** (index hash, not `Math.random`) — keep the backdrop hydration-safe.
- **`ENABLE_NEST_AUDIO` stays OFF** until real files + a gesture-gated player ship (browsers block
  autoplay; the flag guards the seam).
- **CSS-only motion** — don't add a motion-library dependency for this; keep everything reduced-motion
  safe.
